## Sobre

Marketplace com fluxo de autenticacao, catalogo, carrinho e checkout, desenvolvido para simular uma experiencia de e-commerce moderna.

O objetivo deste repositorio e demonstrar uma implementacao clara, organizada e facil de avaliar, com documentacao objetiva para recrutadores e pessoas tecnicas entenderem rapidamente o contexto do projeto.

## Funcionalidades

- Autenticacao mockada.
- Catalogo de produtos.
- Carrinho.
- Checkout.
- Formularios validados.
- Persistencia no cliente.
- Tema claro/escuro.

## Stack

- **Next.js 16**
- **React 19**
- **TypeScript**
- **TanStack Query**
- **TanStack Form**
- **React Hook Form**
- **Radix UI**
- **Tailwind CSS**
- **Zod**

## Como executar

```bash
git clone https://github.com/marquesmaycon/marketplace-nextjs.git
cd marketplace-nextjs
npm install
npm run dev
```

## Scripts disponiveis

- `npm run dev`
- `npm run build`
- `npm run start`
- `npm run lint`
- `npm run create-env`

## Destaques tecnicos

- Fluxo completo de e-commerce.
- Boa vitrine de produto e formularios.
- Uso de TanStack e validação com Zod.
